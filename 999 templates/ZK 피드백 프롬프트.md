# ZK 노트 피드백 프롬프트

> 다른 채팅 세션에서 이 채팅의 맥락 없이 ZK 영구 노트 피드백/개선을 받을 때 쓰는 프롬프트.
> 아래 코드블록을 복사 → `@ZK/노트파일명.md` 부분만 대상 노트로 교체해서 사용.

```
@ZK/노트파일명.md

이 노트는 Folgezettel 방식 Zettelkasten의 영구 노트(permanent note)야.
아래 기준으로 노트를 평가하고 개선해줘.

## 이 vault의 ZK 규칙
- ZK/ 폴더 = 영구 노트 (Folgezettel ID: 1 → 1a → 1a1, 형제는 1a → 1b)
- content/ 폴더 = 기존 장문 레퍼런스 노트 (type: reference)
- ZK-Index/ 폴더 = 키워드 인덱스
- frontmatter: id, type, up(상위 노트 wikilink), created, tags
- 본문 구조: 제목 → 핵심 문장 한 줄 → 본문 → ## 연결

## 평가·개선해줄 것
1. **원자성**: 노트가 "하나의 재사용 가능한 아이디어"에 집중하는지.
   개별 사건 로그와 일반화된 교훈이 섞여 있으면, 제목 아래 핵심 문장을
   "나중에 다시 꺼내 쓸 수 있는 교훈" 형태로 다듬어줘.
2. **tags**: 상위 노트(up)의 태그와 일관되게, 그리고 "나중에 이 단어로
   검색해 비슷한 노트를 모으고 싶은가" 기준으로 제안.
3. **연결(## 연결)**: vault 안에서 실제로 관련된 노트를 검색해서 찾아줘.
   - content/ 의 기존 레퍼런스 노트 중 주제가 겹치는 것
   - 같은 부모 아래 형제 노트
   - 억지 연결은 금지. 정말 없으면 "비워두는 게 맞다"고 말해줘.
4. 본문이 너무 빈약하거나 모호하면 구조(원인/개선 등)를 잡아줘.

먼저 평가를 말해주고, 내가 동의하면 파일을 직접 수정해줘.
```

## 변형 옵션
- **바로 수정**: 마지막 줄("먼저 평가를…")을 빼면 평가 없이 즉시 수정.
- **평가만**: 마지막 줄을 "수정하지 말고 평가만 해줘"로 교체.
- **여러 노트 일괄**: 첫 줄에 `@ZK/노트1.md @ZK/노트2.md` 처럼 여러 개 첨부.
