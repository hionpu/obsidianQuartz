# 1a 자료구조

핵심 질문: **어떤 연산이 얼마나 자주 발생하는가?**
이 답이 자료구조 선택을 결정한다. 구조를 먼저 고르고 용도를 끼워 맞추는 건 역방향.

## 핵심 선택 기준

| 구조 | 최적 연산 | 트레이드오프 |
|------|-----------|--------------|
| 세그먼트 트리 | 범위 쿼리 + 업데이트 O(log N) | 구현 복잡도, 메모리 4N |
| B-Tree | 디스크 기반 정렬 탐색 | 삽입/삭제 시 재균형 비용 |
| 해시맵 | 단일 키 O(1) 접근 | 순서 없음, 충돌 처리 |
| 우선순위 큐 | 최솟값/최댓값 추출 | 임의 접근 불가 |

## 세그먼트 트리 선택 조건
범위 업데이트가 있다면 → **Lazy Propagation** 필수.
없다면 → 일반 세그먼트 트리 또는 BIT(Fenwick Tree)로 충분.
