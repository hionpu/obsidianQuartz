# 1b 알고리즘 패턴

핵심 통찰: **알고리즘 문제는 대부분 소수의 패턴으로 분류된다.**
패턴을 인식하는 능력 = 구현보다 훨씬 중요한 스킬.

## 주요 패턴 분류

### Dynamic Programming
- **선택지**: 취하거나 / 취하지 않거나
- **상태**: 현재까지의 최적값을 메모이제이션
- **변형**: Bitmask DP (집합 상태), Tree DP (트리 위에서)
- 적용 신호: 부분 문제가 겹치고, 최적 부분 구조가 있을 때

### Greedy
- **선택지**: 현재 시점에서 가장 좋은 것을 선택
- **조건**: 탐욕적 선택이 전역 최적을 보장할 수 있을 때만 유효
- 적용 신호: 정렬 후 순서대로 처리, Exchange Argument로 증명 가능

### Graph
- **SCC (강연결요소)**: 방향 그래프에서 서로 도달 가능한 최대 집합
- **위상정렬**: DAG에서 의존성 순서 결정
- 적용 신호: 순환 탐지, 의존성 문제, 최단경로
