# 2b 인터페이스 설계

핵심 질문: **이 추상화가 실제로 필요한가, 아니면 습관적으로 추가한 것인가?**

## 단일 구현 인터페이스 문제

인터페이스를 만들어야 하는 진짜 이유:
1. **테스트**: Mock/Stub으로 교체해서 단위 테스트가 필요할 때
2. **다형성**: 미래에 구현체가 2개 이상 생길 가능성이 명확할 때
3. **의존성 역전**: 상위 모듈이 하위 모듈에 직접 의존하지 않아야 할 때

이 세 가지 중 하나도 아니면 → 인터페이스 없이 구체 클래스 직접 사용이 맞다.

"언젠가 필요할 수도 있으니" = YAGNI 위반.

## 추상화 레벨 결정 원칙
- 같은 레벨의 개념끼리 묶어라
- 구현 세부사항이 인터페이스에 새어나오면 추상화 레벨이 맞지 않는 것
