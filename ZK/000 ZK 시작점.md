## 규칙
- **영구 노트(permanent)**: `ZK/` 폴더, ID + 제목 파일명
- **키워드 인덱스(index)**: `ZK-Index/` 폴더
- **레퍼런스 노트(reference)**: `content/` 폴더 (기존 장문 노트)
- **새 ZK 노트 ID**: 상위 노트 ID + 알파벳 (예: `1a` → `1a1`, `1a2`)
- **템플릿**: `999 templates/ZK permanent note`
