# 1c 네트워크 프로토콜

핵심 통찰: **HTTP는 무상태(stateless)다.**
모든 인증 문제는 이 무상태성을 어떻게 다루는가의 문제다.

## 계층 구조 (OSI 관점)

```
응용 계층:  HTTP / HTTPS
보안 계층:  TLS (SSL의 후계)
전송 계층:  TCP
네트워크:   IP
```

HTTPS = HTTP + TLS. 암호화는 TLS가 담당, 통신 규약은 HTTP가 담당.

## 인증 방식 선택

| 방식 | 상태 저장 위치 | 장점 | 단점 |
|------|---------------|------|------|
| 세션 | 서버 메모리/DB | 즉시 무효화 가능 | 서버 부하, 수평 확장 어려움 |
| JWT | 클라이언트 | 무상태, 확장 용이 | 토큰 무효화 어려움 |

선택 기준: 로그아웃 즉시 반영이 중요하면 세션. 마이크로서비스/무상태 API면 JWT.

## REST 설계 원칙
리소스를 명사로, 행위를 HTTP 메서드로 표현.
`GET /users/1` vs `POST /users/1/delete` — 후자는 RESTful하지 않다.
