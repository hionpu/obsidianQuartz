# obsidian-zettelkasten-navigation 설치 가이드

## 1. 플러그인 다운로드

```powershell
# vault 루트에서 실행
cd D:\PortableGit\obsidianQuartz\.obsidian\plugins
git clone https://github.com/pkm-er/obsidian-zettelkasten-navigation.git
```

또는 수동으로:
1. https://github.com/pkm-er/obsidian-zettelkasten-navigation/releases 에서 최신 릴리즈 다운로드
2. `main.js`, `manifest.json`, `styles.css` 를 `.obsidian/plugins/obsidian-zettelkasten-navigation/` 에 복사

## 2. Obsidian 설정

Obsidian 재시작 → Settings → Community plugins → 설치된 플러그인 목록에서 활성화

## 3. 플러그인 설정값

Settings → Zettelkasten Navigation:

| 설정 항목 | 값 |
|-----------|-----|
| Main note folder | `ZK` |
| Index folder | `ZK-Index` |
| ID location | `Filename prefix` |
| ID separator | ` ` (공백) |

## 4. 사용법

- **zk-index-graph-view**: 전체 ZK 구조를 Folgezettel 계층으로 시각화
- **zk-local-graph-view**: 현재 노트 기준 로컬 연결 그래프

리본 아이콘 또는 커맨드 팔레트(`Ctrl+P`)에서 `Zettelkasten` 검색.

## 5. 이 vault의 ZK 구조 요약

```
ZK/
  000 ZK 시작점.md    ← 여기서 시작
  1 CS 기초 개념.md
  1a 자료구조.md
  1b 알고리즘 패턴.md
  ...

ZK-Index/
  세그먼트-트리.md    ← 키워드로 탐색
  TDD.md
  ...

content/             ← 기존 장문 노트 (type: reference)
```
