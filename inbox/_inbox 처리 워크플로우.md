# 📥 inbox 처리 워크플로우

> 이 폴더 = **떠오른 생각을 0.5초 안에 던지는 임시 그물.**
> 쌓이는 곳이 아니라 **통과하는 곳.** 처리 후 inbox는 비어 있어야 정상.

---

## 캡처 (운동 중 / 이동 중 / 자기 전, 주로 모바일)

- 모바일 Obsidian에서 새 노트 → **한 줄 쓰고 끝.** 템플릿·태그·제목 신경 X.
- 분야 무관. 코드든 영상 아이디어든 게임이든 다 여기로.
- 파일명도 대충 (앞부분 몇 글자 자동이면 됨).
- 다 쓰면 git sync (모바일 → PC 자동 반영).

예시:
```
인트로 길면 이탈하더라
약초꾼 게임에 날씨 시스템?
Elixir GenServer 상태 영속화 방법 찾기
```

---

## 처리 (PC에서, 정해진 주기에 — 예: 하루 한 번 5분)

`inbox/`의 메모를 하나씩 보며 **3가지 중 하나**로 결정:

| 판단 | 행동 |
|------|------|
| 🟢 쓸만한 아이디어 | → `ZK/`에 permanent note로 **내 말로 재구성** → inbox 원본 **삭제** |
| 🟡 자료 / 할 일 / 링크 | → 알맞은 곳(`content/`, 할일앱 등)으로 이동 → inbox에서 제거 |
| 🔴 별로 / 이미 있음 | → 그냥 **삭제** |

**핵심: inbox를 비우는 게 목표.** 노트를 남기는 게 아니라 흘려보내는 것.

---

## 언제까지 처리하나

숫자 규칙(48시간 등)은 신경 X. 진짜 기준:

> **"이게 뭐였더라?" 상태가 되기 전에 처리하라.**

기억이 살아있는 동안 소화. 보통 1~2일. 본인 리듬대로 (매일 저녁이든 주말 몰아서든).

---

## 원칙 한 줄
**inbox는 통과하는 곳이지 쌓이는 곳이 아니다.**
처리 안 된 메모가 쌓이면 → 죄책감 더미 + 검색 오염. 비우지 못할 바엔 과감히 삭제.
