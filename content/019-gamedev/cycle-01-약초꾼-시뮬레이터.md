# Cycle 01 — 필드 채집 타임어택

> 마스터 플랜: [[content/019-gamedev/product-cycle과-세계관.md]]

**사이클 목표**: Steam 출시 파이프라인 최초 학습 (Steamworks, 스토어 페이지, 빌드 배포, 리뷰 대응) + Unity 기본

| 항목 | 결정 |
|---|---|
| 장르 | 필드 채집 타임어택 (Steam PC 캐주얼) |
| 플랫폼 | Steam |
| 수익화 | 유료 ($1~3) |
| 세계관 위치 | 의원 수습생 시절 — 2번 의원 시뮬레이터의 직접 예고편 |

---

## 1. 핵심 메커닉

### 1.1 필드 채집 구조

```
┌─────────────────────────┐
│  🌿   🌿        🌿      │
│      🌿    🌿           │
│  🌿           🌿   🌿   │
│        [주인공]          │
│  🌿   🌿        🌿      │
└─────────────────────────┘
  WASD 자유 이동 / 타이머 카운트다운
  약초에 닿으면 수집
```

- **필드**: 화면 안에 들어오는 작은 구역. 한쪽 끝에서 반대쪽 끝까지 10~20초 내외
- **주인공**: WASD 자유 이동
- **약초**: 필드 내 랜덤 배치 — 닿으면 자동 수집
- **타이머**: 라운드당 제한 시간. 소진 시 라운드 종료
- **라운드**: 타이머 종료 → 수집 결과 평가 → 다음 라운드

### 1.2 검증할 핵심 질문

> "제한 시간 안에 필드를 돌아다니며 약초를 줍는 행위가 기본적으로 재미있는가?"

이것만 확인하면 프로토타입 목표 달성.

---

## 2. 프로토타입 구현 목록

> **범위 원칙**: 오행·환자·업그레이드 없음. 이동과 수집의 느낌만 검증.

```
1. 필드 정의        일정 크기의 플레이 구역 설정
2. 캐릭터 이동      WASD 자유 이동, 필드 경계 충돌
3. 약초 배치        오브젝트 N개 랜덤 배치 (속성 구분 없음)
4. 수집 감지        캐릭터 ↔ 약초 충돌 → 수집 처리 (약초 제거)
5. 타이머           카운트다운, 소진 시 라운드 종료
6. 수집 카운트      라운드 내 수집 개수 표시
```

플레이해보고 재미있으면 아래 미결 사항으로 넘어간다.

---

## 3. 미결 사항 (프로토타입 이후 판단)

프로토타입 느낌 확인 전에 설계해봤자 버릴 가능성이 높은 것들.

### 3.1 오행 블렌딩 방식

| 후보 | 설명 | 비고 |
|---|---|---|
| **A. 환자 처방 목표형** | 환자가 필요한 속성 알려줌 → 해당 약초만 수집 | 가장 단순, 기본 후보 |
| **C. 필드 속성형** | 필드마다 오행 테마 → 어느 필드 진입할지가 판단 | A 위에 레이어로 추가 가능 |

B안 (도구-속성 매칭) 은 게임 방식이 너무 심플해져서 제외.

### 3.2 난이도 스케일링

라운드가 지날수록 무엇이 어려워지는가:
- 동시 환자 수 증가 (1명 → 2명 → 3명) → 약초 자원 배분 판단 필요
- 약초 HP 증가 → 도구 업그레이드 필요
- 필드 내 약초 밀집도/분포 복잡화
- 위 중 어느 축을 주 난이도로 쓸지 미결

### 3.3 패널티 시스템

잘못된 약초 수집 시 어떻게 되는가:
- 환자 수치 악화 (오행 과다 → 부작용)
- 슬롯 낭비만 (수집 자체는 무해)
- 없음 (필요한 것만 골라 수집하면 됨)

→ "모든 약초 다 캐면 게임이 쉬워지는" 문제와 직결. 프로토타입 플레이 후 판단.

### 3.4 업그레이드 시스템

라운드 사이 업그레이드 후보:
- 데미지 ↑ (약초 수집 타격 횟수 감소)
- 이동속도 ↑
- 범위 ↑ (근처 약초 동시 수집, 포지셔닝 실력 필요)
- 도구 속성 (특정 오행 약초 1타 수집)

→ 업그레이드 시스템 자체가 필요한지도 프로토타입 이후 판단.

### 3.5 실력 표현 요소

무엇이 잘하는 플레이어와 못하는 플레이어를 구분하는가:
- 포지셔닝 (범위 업 시 틀린 약초 피해 스윙)
- 경로 최적화 (짧은 시간에 더 많이 수집)
- 우선순위 판단 (환자 여럿일 때 자원 배분)

## 4. 오행 시스템 (확정분)

오행 블렌딩 방식이 미결이어도, 약초 속성 자체는 고정.

### MVP 범위
목(木) / 화(火) / 수(水) + 음양 — 총 5개 변수

토(土) / 금(金)은 업데이트로 추가

### 약초 종류
| 오행 | 약초 예시 | 효과 |
|---|---|---|
| 목(木) | 청목초, 산쑥, 새싹버섯 | 목기 +N |
| 화(火) | 홍화, 불꽃뿌리, 산초 | 화기 +N |
| 수(水) | 수련잎, 냉초, 이슬풀 | 수기 +N |
| 음(陰) | 달빛초, 서리꽃 | 음기 +N |
| 양(陽) | 햇살풀, 황금꽃 | 양기 +N |

### 업데이트 추가 예정
- 토(土): 황토근, 갈근 등
- 금(金): 은사초, 백금화 등
- **오행 상생상극**: 수생목(수기 약초 → 목기 보너스) 등

---

## 5. 환자 시스템 (확정분)

오행 블렌딩 방식 확정 후 세부 설계. 기본 구조만 고정.

- 환자마다 고유한 기본 체질 (정상 수치)
- 현재 상태 = 기본 체질에서 편차 발생
- 치료 목표 = 편차를 정상 범위로 복원

### 환자 종류 (MVP 5종)
| 환자 | 증세 | 필요 |
|---|---|---|
| 전사 (가벼운 부상) | 양기 소진 | 양기↑ |
| 상인 (피로) | 수기 부족 | 수기↑ |
| 노인 (허약) | 목기 부족 + 음기 과다 | 목기↑ 음기↓ |
| 임산부 | 화기 과다 | 화기↓ |
| 어린이 (열병) | 수기 부족 + 화기 과다 | 수기↑ 화기↓ |

## 6. 기능 추가 순서 (프로토타입 이후)

프로토타입 검증 후 순서대로 붙임.

| 단계 | 기능 |
|---|---|
| **1단계** | 오행 속성 적용, 환자 1명, 수집 목표 표시 |
| **2단계** | 환자 5종, 난이도 곡선 기초, 라운드 구조 |
| **3단계** | 업그레이드 시스템 (미결 사항 3.4 확정 후) |
| **4단계** | Steam Achievements, 글로벌 리더보드, 컨트롤러 지원 |
| **출시 전** | 세이브/로드, 튜토리얼, 스팀 스토어 페이지 완성 |
| **업데이트** | 오행 5개 풀셋, 환자 종류 확장 |

---

## 7. 세계관 연결

- **2번 의원 시뮬레이터와의 관계**: 이 게임은 의원 수습생 시절. 2번은 수습 수료 후 본격 의원 운영.
- **2번 메커닉의 캐주얼 버전**: "환자 상태 파악 → 적절한 약초 채집" 핵심 루프가 동일.
- **배경**: 도시 외곽 산야. 스승 NPC에게 환자 상태를 전달받고, 수습생이 산속 필드로 나가 필요한 약초를 채집해오는 구조.
