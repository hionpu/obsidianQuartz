# Cycle 01 — 오행 약초 처방 미니게임

> 마스터 플랜: [[content/019-gamedev/product-cycle과-세계관.md]]

**사이클 목표**: 출시 파이프라인 전체 학습 (Google Play Console, GRAC, 정책, 트레일러) + Unity 기본

| 항목 | 결정 |
|---|---|
| 장르 | 오행 약초 채집 레인 러너 (캐주얼 모바일) |
| 플랫폼 | Android 우선, 다운로드/매출에 따라 iOS 추가 |
| 수익화 | F2P + 인앱결제 (목숨/계속하기, 스킨) |
| 세계관 위치 | 의원 수습생 시절 — 2번 의원 시뮬레이터의 직접 예고편 |

---

## 1. 핵심 메커닉

### 1.1 러닝 채집 구조

```
↑ 달리기 방향 (화면 위쪽)
┌──────────────────────┐
│  🌿목   🪨    💧수   │  ← 지형·약초·장애물이 아래로 스크롤
│                      │
│  🔥화   🌿목  🪨     │
│                      │
│  💧수   🌿목  🔥화   │
│                      │
│  [ 레인1 레인2 레인3 ]│
│       [주인공]        │  ← 화면 하단 고정, 런 모션만
└──────────────────────┘
  ← 스와이프로 레인 이동 →
```

- **주인공**: 화면 하단에 고정, 달리기 애니메이션만 재생
- **지형**: 아래로 스크롤 (주인공이 앞으로 달리는 효과)
- **레인**: 3개 기본 (좌/중/우). 스와이프 또는 좌우 탭으로 이동
- **약초**: 레인 위에 등장 — 해당 레인에 있으면 자동 수집
- **장애물**: 레인 위에 등장 — 충돌 시 수치 악화 또는 목숨 차감

### 1.2 오행 판단 루프

```
[환자 상태 패널 (화면 상단 고정)]
 목기 ▓▓░░░  ← 부족
 화기 ▓▓▓▓░  ← 약간 부족
 수기 ▓▓▓▓▓▓ ← 과다
 힌트: "목기↑ 수기↓ 필요"

        ↓ 달리면서 판단

  필요한 약초 레인으로 이동해 수집
  불필요하거나 과다한 속성 약초 레인은 회피
  장애물도 회피

        ↓ 실시간 수치 변화

 수집 약초 속성 → 환자 수치 즉시 변동
 정상값 도달 → 치료 성공 + 다음 환자 등장
 장애물 충돌 or 타이머 소진 → 게임 오버
```

**핵심 재미**: "이 환자에게 지금 뭐가 필요한가"를 빠르게 파악하고, 달리면서 레인을 실시간으로 선택. 판단력 + 반사신경 + 이동 타이밍.

### 1.3 낙하물 방식 대비 장점

| 항목 | 기존 (낙하물 받기) | 변경안 (레인 러너) |
|---|---|---|
| 세계관 적합성 | 약초가 하늘에서 떨어짐 (어색) | 약초꾼이 산야를 달리며 채집 (자연스러움) |
| 조작감 | 받기 전 위치 선점 | 이동 + 회피 동시 → 더 다이나믹 |
| 모바일 핏 | 좌우 드래그 | 스와이프/탭 (엄지 원핸드 최적) |
| 시각적 흥미 | 정적 화면 | 스크롤로 진행감·속도감 제공 |
| 장애물 통합 | 별도 설계 필요 | 레인 구조에 자연스럽게 통합 |

## 2. 난이도 곡선

| 단계 | 환자 상태 | 장애물 | 스크롤 속도 | 설명 |
|---|---|---|---|---|
| 초반 | 오행 1개 부족 | 거의 없음 | 느림 | 원하는 레인 이동만 하면 됨 |
| 중반 | 부족 1개 + 과다 1개 | 간헐적 | 중간 | 필요 약초 수집 + 불필요 약초 레인 회피 병행 |
| 후반 | 복합 불균형 (2~3개) | 빈번 | 빠름 | 우선순위 판단 + 장애물 회피 동시 |
| 스페셜 | 음양 불균형 포함 | 밀집 패턴 | 매우 빠름 | 최고 난이도, 순간 판단 요구 |

> **장애물 종류 (MVP)**: 바위, 가시덤불, 쓰러진 나무. 시각적으로 오행 약초와 명확히 구분.

## 3. 오행 시스템

### MVP 범위
목(木) / 화(火) / 수(水) + 음양 — 총 5개 변수

토(土) / 금(金)은 업데이트로 추가

### 약초 종류 (MVP)
| 오행 | 약초 예시 | 효과 |
|---|---|---|
| 목(木) | 청목초, 산쑥, 새싹버섯 | 목기 +N |
| 화(火) | 홍화, 불꽃뿌리, 산초 | 화기 +N |
| 수(水) | 수련잎, 냉초, 이슬풀 | 수기 +N |
| 음(陰) | 달빛초, 서리꽃 | 음기 +N |
| 양(陽) | 햇살풀, 황금꽃 | 양기 +N |

### 업데이트 추가 예정
- 토(土): 황토근, 갈근 등
- 금(金): 은사초, 백금화 등
- **오행 상생상극 상호작용**: 수생목(수기 약초 → 목기 보너스), 화극금 등

---

## 4. 환자 시스템

- 환자마다 고유한 기본 체질 (정상 수치)
- 현재 상태 = 기본 체질에서 편차 발생
- 치료 목표 = 편차를 정상 범위로 복원

### 환자 종류 (MVP 5종)
| 환자 | 증세 | 필요 |
|---|---|---|
| 전사 (가벼운 부상) | 양기 소진 | 양기↑ |
| 상인 (피로) | 수기 부족 | 수기↑ |
| 노인 (허약) | 목기 부족 + 음기 과다 | 목기↑ 음기↓ |
| 임산부 | 화기 과다 | 화기↓ |
| 어린이 (열병) | 수기 부족 + 화기 과다 | 수기↑ 화기↓ |

---

## 5. MVP 구현 목록 (바이브코딩)

> Unity 에디터에서 플레이 가능한 수준. UI 없이 핵심 피드백 루프만.

```
1. 레인 시스템          레인 3개 정의, 레인별 X 좌표 고정
2. 캐릭터 레인 이동     스와이프/탭 → 인접 레인으로 이동 (Tween)
3. 지형 스크롤러        배경·오브젝트가 일정 속도로 아래로 스크롤
4. 약초 스포너          오행 3종 랜덤 레인에 등장, 스크롤과 동기화
5. 장애물 스포너        레인별 랜덤 등장 (바위, 가시덤불 등)
6. 수집/충돌 감지       캐릭터 레인 == 오브젝트 레인 → 수집 or 피해
7. 환자 상태 데이터     목/화/수/음/양 수치 (현재값 + 목표값)
8. 수치 업데이트        수집 약초 속성 → 환자 수치 실시간 변화
9. 점수 계산            목표값 달성도에 따라 점수, 치료 완료 시 보너스
10. 게임 오버           타이머 소진 or 장애물 누적 피해 한계
```

## 6. TDD+BDD 단계 추가 순서

| 우선순위 | 기능 |
|---|---|
| **높음** | 환자 UI (수치 게이지바), 약초 비주얼 구분, 점수 UI, 하이스코어 |
| **중간** | 환자 5종 전부 구현, 난이도 곡선 조정, 연속 치료 콤보 보너스 |
| **낮음** | 오행 토/금 추가, 상생상극 상호작용, BGM/SFX |
| **출시 전** | Unity IAP (목숨/계속하기), 세이브/로드, 튜토리얼, 개인정보처리방침 |
| **업데이트** | 오행 5개 풀셋, 환자 종류 확장, 스킨 시스템 |

## 7. 세계관 연결

- **2번 의원 시뮬레이터와의 관계**: 이 게임은 의원 수습생 시절. 2번은 수습 수료 후 본격 의원 운영.
- **2번 메커닉의 캐주얼 버전**: "환자 상태 파악 → 적절한 약초 처방" 핵심 루프가 동일.
- **배경**: 도시 외곽 산야. 스승 NPC에게 환자 상태를 전달받고, 수습생이 산속으로 달려가 필요한 약초를 채집해 돌아오는 구조. 레인 러너는 "채집 구간"을 표현.
