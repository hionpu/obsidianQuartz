# 챕터 구성 (확정)

## 1. 인트로 — 마우스 에임의 착각
- 원클립 트래킹 매드무비 (10~15초)
- "이게 마우스 컨트롤만일까?" 질문 → 호기심 유발
- "키보드 에임" 마스터 가이드 훅

## 2. 키보드 에임의 원리
### 2-1. 근본 목적 (왜 하는가)
- 마구잡이로 좌우 움직이는 적을 마우스로만 따라가면 → 에임이 휘청이고 저점이 낮음
- 키보드로 적과의 **상대속도를 줄여** 에임을 쉽게 만드는 게 목적
	- *(부가 설명 — "왜 쉬워지는가")*
	- 대부분의 게임은 나와 상대의 이동 속도가 같음 → 미러링하면 **상대속도 = 0** → 마우스를 움직일 필요가 없어 **트래킹 변수 하나가 통째로 사라짐**
	- 상대속도가 0이 안 되더라도(>0), 미러링 안 할 때보다 **상대속도를 "줄이는"** 효과 → 변수를 작게 만듦
	- 직관: 같은 크기 타겟이면 **느린 타겟이 트래킹하기 쉬움** → 코박스 Fast Strafe vs Slow Strafe 시나리오를 자료 화면으로 대비
- **미러링이 기본** / **안티 미러링은 "미러링이 어긋나는 순간의 대처"** (미러링이 메인, 안티가 보조)
	- 단, 미러링도 수동적 따라가기가 아니라 **능동적으로** 해야 함
	- 상대가 방향 전환 없이 한쪽으로만 쭉 가는 경우 → fake mirroring을 하거나, 미러링을 풀고 **나만의 strafe**를 하는 것도 좋음 → 이럴 때 **안티 미러링이 빛을 발함**
- 에이펙스 리코일 스무딩 → 방향키 무빙 = 수직 반동 제어와 직결

### 2-2. 효율을 결정하는 변수
- **거리(각속도)**: 같은 strafe라도 근거리는 크로스헤어가 크게 휙, 원거리는 거의 안 움직임
	- → 키보드 에임은 **근거리일수록 강력**, 원거리는 마우스 비중↑
- **ADS 이동 속도**: 조준 시 속도 느려짐 → 미러링 주기·strafe 폭이 달라짐 (무기별 ADS 속도 차이도 영향)

### 2-3. 키보드 무빙은 양날의 검 (공격 vs 방어)
- 미러링하면 내 에임은 쉬워지지만 → 나도 **예측 가능**해져 상대 에임도 쉬워짐
- 반대로 마구 피하면 → 나는 안 맞지만 내 에임도 어려워짐
- 이 **긴장 관계**가 다음 치킨 게임 문제(2-4)의 뿌리이자 fake mirroring이 존재하는 이유

### 2-4. 미러링의 한계와 해결 (치킨 게임 문제)
- 흔한 걱정: "내가 미러링하면 쉬워지지만, 상대도 같이 미러링하면 양쪽 다 쉬워져 치킨 게임 아니냐?"
	- *(보강 — 왜 교착이 되는가)*: 둘 다 미러링하려는 마음으로 마주치면 **어느 누구도 방향을 틀지 않음**
	- 이유는 단순함 — 미러링의 원칙 자체가 **"상대가 방향을 안 틀면 나도 안 튼다"**이기 때문 (상대 방향에 맞추는 게 미러링이므로)
	- 결과: 무빙으로는 우열이 안 갈리고 **순수 raw 에임 싸움 = 치킨 게임** → 이 교착을 깨는 도구가 아래 해결책들
- 해결 1 — **미러링 주기와 ping**
	- strafing이 너무 짧으면 = 제자리, 너무 길면 = 미러링 치킨 게임 → 적정 주기 필요
	- ping 50ms 내외면, 방향 전환 때문에 미러링이 안 되는 틈이 strafing 주기의 **10~20%** 차지
	- 📹 *자료 화면*: 교전 중 좌우로 움직이는 상대 클립 → "이 정도면 적절한 strafe 주기인데, 1초에 방향이 N번 바뀌었으므로..." 식으로 주기를 짚고 10~20% 수치를 시각적으로 뒷받침
- 해결 2 — **Fake mirroring** (개념만 짧게, 자세한 건 3-4 심화에서)
	- 미러링하다 아주 잠깐 반대로 → 다시 미러링 → 나는 계속 미러링이지만 상대는 페이크 대처하느라 에임 흔들림

## 3. 실전 연습 가이드
### 3-1. 요소 해부 및 기초 훈련 (KovaaK's)
- 미러링 / 안티 미러링 / 내 무빙 중 크로스헤어 안정화로 분해
- 무빙 에이밍 전용 시나리오 추천 (Close Fast Strafes Dodge, Mirror Dodge 등)
- **에임 트레이닝 종목 (키보드 에임용)**
	- **Smoothing** (speed matching 포함)
	- 다양한 range에서의 **strafe 시나리오** (close / mid / far)
- 📝 *TODO*: 아직 더 생각해야 할 시나리오 추가 필요 (목록 보강 예정)

### 3-2. 연습과 실전의 브릿지 (엔진 물리 적응)
- 코박스 ↔ 실게임 물리/가속도/히트박스 차이 좁히는 징검다리
- 에이펙스: R5Reloaded 1v1 서버
- 오버워치: 사설 워크샵 (VAXTA 코드)

### 3-3. 랭크 게임에서의 의도적 수련 (Deliberate Practice)
- 승패·킬데스·RP 같은 결과 수치는 머릿속에서 지움
- 오직 "이번 교전에서 키보드 에임을 의식적으로 썼나?" Y/N로만 자기 평가
- 반복 → 의식적 피지컬을 무의식 반응으로 내재화
- **연습이 잘 됐는지 확인하는 척도**
	- 조건 1 — **랭크 게임**에서: 인지 부하가 심하고 RP가 깎인다는 불안한 환경
	- 조건 2 — **의식하지 않고도**
	- 이 두 조건에서 키보드 에임을 수행하고 있다면 → 잘 되고 있는 것 (내재화 완료 신호)
- **VOD 리뷰 피드백 루프**: 자기 클립을 다시 보며 "이 교전에서 미러링했나?" 체크 → 의식적 평가를 객관화

### 3-4. 심화 과정
- **Fake mirroring** 실전 적용 (2-4 개념을 여기서 풀이)
	- 방법 자체는 간단함
- **의도적 미러링 ↔ 안티 미러링 전환 훈련**
	- KovaaK's dodge 시나리오에서 계속 좌우 strafing하는 적에게
	- 한 시나리오 안에서 일부러 미러링과 안티 미러링을 전환 → 방향 전환 대처 능력 내재화
- **초고속 strafe 대처 (제자리 수준은 아니지만 매우 빠른 strafe)**
	- 상황: 인간 반응속도(150~250ms)에 가까운 주기로 방향 전환, 혹은 거의 제자리 수준 전환 → 당하는 입장에선 에임이 심하게 흔들릴 수밖에 없음
	- 대처법:
		1. 미러링을 풀고 **나는 한 방향으로** 움직인다
		2. 마우스로 트래킹하려 하지 말고, 적이 움직이는 **중간쯤에 크로스헤어를 둔다**
	- 이렇게 안 하면 → **무한 오버슈팅 지옥**에 빠짐
	- *(보강)* 반응속도 끌어올리는 코박스 순서: `controlsphere far larger` → `close strafe invincible` → `close fast strafe invincible`
		- 단, 마지막 시나리오는 좌우 전환이 매우 빨라 **오버슈팅이 너무 많이 나면 중단 권장** (나쁜 습관 강화 우려)

### 3-5. 흔한 실수 (Common Mistakes) — ❌ → ✅ 비포애프터
- 일정한 리듬으로 strafe → 상대가 패턴을 읽음
- 너무 넓게 strafe → 오히려 크로스헤어가 과하게 흔들림
- ADS 중인데 strafe를 멈춤 / 패닉 A-D 연타
- (각 실수마다 잘못된 예 → 교정된 예를 짧게 대비해서 보여주기)

### 3-6. 데일리 연습 루틴 (전체 묶기)
- 순서: 코박스 워밍업 → 브릿지(R5/워크샵) → 랭크 실전
- 하루 권장 시간 배분 제시 → "이걸 실제로 어떻게 돌리나"의 답

## 4. 하드웨어 노트
- **Rapid trigger(자석축 / 홀이펙트 스위치)만으로도 키보드 에임 용도로는 충분**
	- 빠른 키 반응 + 짧은 액추에이션 → 타이트한 strafe 가능, 굳이 더 갈 필요 없음
- **Null bind / SOCD / SnapTap** (선택, ⚠️ 주의)
	- A+D 동시 입력을 마지막 입력으로 처리 → 방향 전환 딜레이 0 → 더 타이트한 strafe
	- 단, **밴 리스크**: CS2는 명시적 금지, 에이펙스는 공식 입장 불명확 → "권장 아님 / 본인 책임" 톤으로 다루기

## 5. 한계 — 키보드 에임이 만능은 아니다
- 원거리 교전, 저격/샷건 한방, 리포지션이 필요한 순간엔 키보드 에임보다 다른 선택이 우선
- 솔직하게 한계를 인정 → 영상 신뢰도↑ (아웃트로 직전 배치)

## 6. 아웃트로 및 넥스트 스텝

- 챕터별 **TL;DR 카드**로 핵심 요약 (시청 유지율↑)
