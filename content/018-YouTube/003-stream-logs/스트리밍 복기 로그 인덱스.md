# 스트리밍 복기 로그 인덱스

매일 아침 VOD 복기로 쌓은 `stream-log` 노트를 한눈에 모으고, 긴 호흡 롱폼(여러 날을 가로지르는 포맷) 제작 때 소스로 쓰는 허브.

- 새 로그 만들 때: `999 templates/stream-log.md` 템플릿 사용
- 로그는 `content/018-YouTube/003-stream-logs` 폴더 아래에 두면 아래 쿼리에 자동 집계됨
- 핵심 규칙: 사건마다 **VOD 타임스탬프 + 고정 태그 + 포맷 후보**를 같이 적기

---

## 태그 세트 (감정/주제 — 이 목록 안에서만 쓰기)

자유 문장 대신 아래 고정 태그를 써야 나중에 "슬럼프 장면 전부", "1대1 굳은 장면 전부"를 한 번에 필터링할 수 있다. 각 태그는 어떤 롱폼 포맷의 소스가 되는지 매핑해 둠.

## RP 추이 (시즌 서사 자동 집계)

```dataview
TABLE WITHOUT ID
  date AS "날짜",
  season AS "시즌",
  rp_start AS "시작 RP",
  rp_end AS "종료 RP",
  rp_delta AS "변동",
  mood AS "컨디션"
FROM "content/018-YouTube/003-stream-logs"
WHERE type = "stream-log"
SORT date DESC
```

## 포맷별 소스 찾기 (편집 들어갈 때)

특정 롱폼을 만들 때, 관련 태그가 달린 로그만 추려 보는 쿼리. 만들려는 포맷에 맞춰 `contains` 태그만 바꿔 쓰면 됨.

### 슬럼프·멘탈 이야기 (#4) 소스
```dataview
LIST
FROM "content/018-YouTube/003-stream-logs"
WHERE type = "stream-log" AND contains(tags, "슬럼프")
SORT date DESC
```

### 1대1 굳음 극복기 (#12) 소스
```dataview
LIST
FROM "content/018-YouTube/003-stream-logs"
WHERE type = "stream-log" AND contains(tags, "1대1굳음")
SORT date DESC
```

### 시즌 명장면 (#5 시즌 리뷰) 소스
```dataview
LIST
FROM "content/018-YouTube/003-stream-logs"
WHERE type = "stream-log" AND contains(tags, "명장면")
SORT date DESC
```

> 다른 포맷도 같은 틀로 복제: `contains(tags, "원하는태그")` 한 줄만 교체.
